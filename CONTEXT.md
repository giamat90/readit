# ReadIt — Project Context

## What it is
Android app: give it a text resource — pasted text, web page URL, PDF, or a photo of printed text — and it reads it aloud (TTS). Library with resume, speed control, voice selection. **Fully standalone — no backend, no account, free.**

## Tech Stack
- **Framework**: Expo (React Native) SDK 55 + TypeScript + Expo Router
- **Storage**: `expo-sqlite` (`readit.db` — documents/chunks/positions, schema + migration runner in `lib/db.ts`); preferences in zustand `persist` → AsyncStorage (`store/preferences.ts`)
- **Extraction** (all on-device, `lib/extraction/`):
  - web — RN `fetch(url)` then Mozilla Readability inside a hidden `react-native-webview`
  - pdf — pdf.js inside the same WebView
  - photo — `@react-native-ml-kit/text-recognition` on-device OCR
  - the WebView page `assets/extraction/engine.html` is generated by `npm run build:engine`
- **TTS**: `expo-speech` on-device (`hooks/useSpeechPlayer.ts`)
- **Styling**: NativeWind (Tailwind for RN)
- **State**: Zustand (`store/preferences.ts`, `store/library.ts`, `store/player.ts`)
- **Build**: local Gradle via the `.bat` scripts + `.github/workflows/release-{apk,aab}.yml`

The **only** network call in the whole app is `fetch(url)` in `lib/extraction/web.ts`.

## Native modules added by the refactor
`expo-sqlite`, `expo-crypto`, `expo-asset`, `react-native-webview`, `expo-image-picker` (config plugin in `app.json` for camera/photos permission), `@react-native-ml-kit/text-recognition`. All autolink through `expo prebuild --clean`. Not Expo Go compatible — use `expo run:android` / the `.bat` scripts.
`@mozilla/readability` + `pdfjs-dist` are **devDependencies** — only used by `scripts/build-extraction-engine.js` to regenerate the committed `engine.html`.

## Riskiest areas (verify on device)
- **PDF** in the WebView — large PDFs (150–200 pp) for memory; scanned/image PDFs correctly return `no_text_found`; password PDFs return `password_protected`.
- **Web** parsing — SPA / paywalled pages yield thin content → surfaces `no_content`; the regex fallback fires if Readability returns < 200 chars.
- **Preferences hydration** — `app/_layout.tsx` awaits `usePreferencesStore.persist.rehydrate()` before first render.

## Decisions made (and why)
- **On-device everything**: privacy (users import private texts), zero running cost, works offline, trivial Play Data Safety ("no data collected").
- **Hidden WebView for web + PDF**: Readability and pdf.js need a real DOM; Android System WebView provides one. HTML is fetched by RN and handed to the WebView as a string so no subresources load.
- **ML Kit for OCR**: replaces the old Claude-vision edge function with a bundled offline model.
- **App language ≠ document language**: Settings' "App language" only changes UI chrome; the voice for a given document is resolved per-document (`detectLanguage` stopword heuristic, then device locale).
